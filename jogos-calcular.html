🧮 FÓRMULA RESOLVENTE (2.º GRAU)
x = (-b ± √(b² - 4ac)) / (2a)
Para equações do tipo ax² + bx + c = 0:
  • b² - 4ac > 0: 2 soluções reais.
  • b² - 4ac = 0: 1 solução dupla.
  • b² - 4ac < 0: Impossível em ℝ.
📐 TEOREMA DE PITÁGORAS
c² = a² + b²
Num triângulo retângulo:
  • c = Hipotenusa (lado maior).
  • a, b = Catetos.
  • Hipotenusa: c = √(a² + b²)
⚡ REGRAS DAS POTÊNCIAS
aⁿ × aᵐ = aⁿ⁺ᵐ | aⁿ ÷ aᵐ = aⁿ⁻ᵐ
Regras principais:
  • Bases iguais: mantém a base e soma/subtrai expoentes.
  • (aⁿ)ᵐ = aⁿˣᵐ (Potência de potência).
  • a⁰ = 1 | a⁻ⁿ = 1 / aⁿ
📈 FUNÇÕES AFINS
f(x) = mx + b
Componentes da reta:
  • m = Declive = (y₂ - y₁) / (x₂ - x₁)
  • b = Ordenada na origem (ponto no eixo Y).
  • Se b = 0, a função é Linear.

Conceitos essenciais:

  • Moda: O valor que mais se repete.
  • Mediana: O valor do meio com dados ordenados.
